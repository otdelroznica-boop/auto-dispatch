# Диспетчерская: эвакуатор и грузовая

Веб-приложение для записи заказов на машины. Работает в браузере на телефоне (iPhone, Android), планшете и компьютере,
ставится на главный экран как приложение. 2–3 пользователя, вход по пин-коду.

## Что умеет

- **Шкала дня.** «Все авто» показывает колонку на каждую машину, выбор машины оставляет одну колонку. Занятое время заштриховано,
  на блоке время, клиент, сумма и отметка оплаты. Нажатие на свободное время открывает запись на это время.
- **Быстрая запись.** Телефон, услуги, сумма. По первым цифрам телефона находится клиент из базы. Если его нет, клиент
  создаётся сам при сохранении. Физлицу достаточно имени, организации можно указать ИНН.
- **Несколько услуг в заказе** из прайса: нажатие добавляет услугу, повторное увеличивает количество. Почасовые услуги
  берут количество часов из длительности заказа. Цену в заказе можно поменять, можно добавить свою услугу.
- **Расчёт и факт.** Расчёт складывается из услуг, «Взяли» показывает, сколько получили с клиента. Долгом считается
  только выполненный заказ, оплаченный не полностью.
- **Водитель** указывается в заказе отдельно от машины, по умолчанию подставляется водитель машины.
- **Защита от двойной записи:** предупреждает, если машина в это время занята.
- **Отчёты за период** (сегодня, неделя, месяц, свой период): по машинам, водителям, услугам, способам оплаты, по дням,
  список долгов. Выгрузка в Excel.
- **Отказы и упущенная прибыль.** Кнопка «Отказ»: звонили, а взять заказ не смогли. Указывается машина, причина,
  требовавшиеся услуги (сумма считается по прайсу), можно отметить «Передали партнёру» и сколько с этого получили.
  Если при записи заказа машина занята, отказ записывается одной кнопкой из окна заказа. В отчёте раздел
  «Упущенная прибыль»: по машинам, услугам и причинам, с фильтрами по машине и услуге.
- **Наёмные машины.** У машины метка «наёмная», владелец и процент, который отдаём владельцу. В отчёте расчёт:
  сколько машина заработала («Взяли»), сколько отдать владельцу, сколько остаётся. В Excel отдельные листы
  «Отказы» и «Наёмные машины».
- **Telegram-бот** присылает водителю и диспетчеру новый заказ, перенос и отмену.
- Кнопки «Позвонить», «Маршрут» (Яндекс.Карты), «Водителю» (текст заказа в WhatsApp или Telegram).
- Автообновление каждые 15 секунд: диспетчер видит изменения, сделанные с телефона.

## Запуск на компьютере

```
pip install -r requirements.txt
python run.py
```

Или двойной клик по `start.bat`. Откроется браузер, первый вход: пользователь **Админ**, пин **1111**.
Сменить пин: Настройки, Пользователи.

Демо-данные (клиенты и заказы за две недели) для показа: `python demo_data.py`, только на пустой базе.

С телефона в той же Wi-Fi сети: адрес `http://<IP компьютера>:8080` (выводится при запуске).

База лежит в `data/dispatch.db` (SQLite, один файл). Бэкап базы = копия этого файла.

## Выкладка в интернет

См. `deploy/УСТАНОВКА_VPS.md`: свой VPS + Caddy (HTTPS автоматически).
Бесплатные Render и Railway не подходят: при перезапуске стирают диск вместе с базой.

## Устройство

- `app/main.py` — API (FastAPI), `app/database.py` — схема SQLite, `app/telegram.py` — уведомления.
- `app/static/` — интерфейс: один `index.html`, `app.js`, `style.css`, без сборки.
